# SOCPilot AI

> A fully local AI-powered Security Operations Center (SOC) assistant that transforms cybersecurity events into structured incident reports using **Meta Llama 3.1** accelerated by **AMD ROCm**.

SOCPilot AI is a prototype AI-powered Security Operations Center assistant developed for the **AMD Radeon Hackathon 2026**.

The project demonstrates how a locally deployed Large Language Model (LLM) can assist security analysts by transforming cybersecurity events into structured incident reports. All inference is performed locally on AMD Radeon GPUs using ROCm without relying on any external AI services.

---

# Overview

Security analysts spend significant time investigating alerts generated by SIEM platforms. Typical tasks include:

- Identifying attack behavior

- Extracting Indicators of Compromise (IOCs)

- Mapping attacks to the MITRE ATT&CK framework

- Assessing severity and confidence

- Generating response recommendations

SOCPilot AI streamlines this workflow through lightweight Python preprocessing and locally deployed Meta Llama 3.1 inference.

The current prototype supports both a command-line workflow and an interactive Gradio web interface for rapid incident analysis.

Current demonstrations use the **CICIDS2017** intrusion detection dataset.

# Installation

Clone the repository.

```bash

git clone https://github.com/cyberbryanzhang/Radeon-hackathon-2026-07.git

cd Radeon-hackathon-2026-07/socpilot-ai

```

Create a virtual environment.

```bash

python -m venv .venv

source .venv/bin/activate

```

Install a ROCm-compatible PyTorch build for your AMD GPU environment.

Then install the remaining dependencies.

```bash

pip install -r requirements.txt

```

---

# Running

## 1. Verify Local LLM

```bash

python app/test_llm.py

```

---

## 2. Generate Dataset Summary

```bash

python app/summarize_dataset.py

```

---

## 3. Command-Line Analysis

```bash

python app/analyze_flow.py outputs/portscan_summary.json

```

The analysis generates:

- JSON Incident Report

- Markdown Incident Report

- Performance Metrics Report

---

## 4. Launch Gradio Web Interface

```bash

python app/web_demo.py

```

Open your browser:

```

http://127.0.0.1:7860

```

Upload a summarized network-flow JSON file to generate:

- Structured Incident Report

- MITRE ATT&CK Mapping

- IOC Extraction

- Security Recommendations

- Markdown Report

- Performance Metrics
